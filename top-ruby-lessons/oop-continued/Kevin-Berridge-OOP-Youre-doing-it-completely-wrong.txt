        SINGLE RESPONSIBILITY PRINCIPLE
            A class has responsibilities that fulfill its purpose. SIMPLER
            doesnt require that a class do only one very narrow thing, ro that it change
            for only a single nitpicky reason, instead SRP requires that a 
            class be cohesive-- that everything the class does be highly related to
            its purpose.
